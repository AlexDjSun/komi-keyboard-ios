# Komi Virtual Keyboard Privacy Policy

Komi Virtual Keyboard processes keyboard input entirely within the current
browser tab.

- It temporarily reads text around the active caret to support capitalization,
  punctuation, cursor movement, and deletion.
- It does not send network requests.
- It does not collect analytics or telemetry.
- It does not store typed text.
- It stores the user's last selected writing system in browser-local storage.
- It keeps only the IDs of tabs where the keyboard is open in temporary browser
  session storage. This state is cleared when a tab closes or the browser exits.

The extension loads a hidden keyboard controller on normal HTTP and HTTPS pages
so an open keyboard can be restored after reload. It becomes visible only in a
tab where the user opened it and can insert text only into a field selected by
the user. Browser security rules prevent it from running on browser-owned pages.

The extension does not sell or transfer user data to third parties. It does not
use user data for purposes unrelated to providing the virtual keyboard, and it
does not use user data to determine creditworthiness or for lending purposes.
